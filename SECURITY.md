# Security Policy

## Supported version

Security fixes are applied to the current `main` branch and the production service at [agaminggod.com](https://agaminggod.com).

## Report a vulnerability

Please use GitHub's private **Report a vulnerability** form for this repository. Do not open a public issue, publish proof-of-concept details, or test against other users' data.

Include:

- The affected route, component, or commit
- Reproduction steps with non-sensitive test data
- Expected and observed behavior
- The likely impact
- Any suggested mitigation

You should receive an acknowledgement within seven days. Please allow a reasonable remediation window before public disclosure.

## Testing boundaries

Use your own accounts, presentations, and sessions. Do not perform denial-of-service testing, automated high-volume scanning, social engineering, credential attacks, or attempts to access data you do not own. The repository includes local and disposable-database test paths for safe verification.
